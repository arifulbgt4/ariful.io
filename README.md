# Engineer Arif Portfolio

> A personal portfolio built with **Next.js**, **React**, **Tailwind CSS**, and **TypeScript**. The site showcases projects, skills, and contact information.

## Getting Started

1. **Clone the repo**:
   ```bash
   git clone https://github.com/<your-username>/engineer-arif-portfolio.git
   cd engineer-arif-portfolio
   ```

2. **Install dependencies** (Node 18+ required):
   ```bash
   npm install
   ```

3. **Run the development server**:
   ```bash
   npm run dev
   ```
   The site will be available at [http://localhost:3000](http://localhost:3000).

## Development

The project uses **Next.js 16** with **React 18** and **TypeScript 5**.

| Command | Description |
|---------|-------------|
| `npm run dev` | Start the Next.js dev server with hot‑refresh. |
| `npm run build` | Build an optimized production bundle. |
| `npm run start` | Run the production build locally. |
| `npm run lint` | Lint TypeScript/JavaScript with ESLint. |

### VS Code Settings (optional)
If you use VS Code, install the following extensions for a smoother workflow:
- Code Spell Checker
- ESLint
- Tailwind CSS IntelliSense
- Prettier – Code formatter

### Environment Variables
Currently the app doesn't rely on any runtime environment variables. If you add any later, create a `next-env.d.ts` automatically generated by Next.

## Build & Deploy

```bash
npm run build
npm run start
```

For deployments you can use Vercel (recommended for Next.js), Netlify, or any Node 18+ server.

## Linting & Formatting

The repo is configured with ESLint and Prettier. Run:
```bash
npm run lint
```
To automatically fix fixable issues, add the `--fix` flag.
